# Social Engineering Awareness Guide

Task 6 · Cyber Security Track · Veda Technology (Level 1, Day 6)

## Task Description
Analyze common social engineering scenarios and identify warning signs.

## Objective
To learn how human behavior can be targeted by attackers.

## Tools Used
- Google Docs

## Deliverable
- Social engineering awareness guide

## What the Guide Covers
- Introduction to social engineering and why it works (trust, authority, urgency, helpfulness, curiosity)
- Common scenarios: phishing, vishing, smishing, pretexting, CEO fraud, baiting, tailgating and quid pro quo
- Warning signs: urgency, impersonation and suspicious requests
- Three example scenarios with the correct action for each
- Tips for employees to prevent social engineering
- What to do if you think you have been targeted
- Interview questions with answers: What is social engineering? What is pretexting? How can employees prevent social engineering?

## Key Learnings
- Attackers target people, not only systems.
- Urgency, impersonation and suspicious requests are the main warning signs.
- Always verify identity through an official channel and never share passwords or OTPs.
- Report suspicious emails, calls and messages to the security team immediately.
